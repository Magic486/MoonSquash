# 验收准备复核

2026-11-26；MoonSquash 0.3.2；十一月赛；账号 Magic486。

当前定位是有明确兼容边界的 SquashFS 4 镜像读写、校验与语义分析库。核心范围已形成从目录/配置构建、读取、校验、查询、提取到差异分析的完整流程。不是完整 squashfs-tools 参数复刻，也不承诺官方验收通过。

## 本轮审查

- 修复 zlib 数据块尾随垃圾被 CLI 接受、扩展文件 inode 的稀疏统计与实际块表不一致仍通过校验的问题。
- 随机访问源的首个 96 字节读取现在严格执行长度合同；短于头部的源在调用回调前拒绝。
- 路径查询与树遍历采用一致的目录项/inode 类型及编号检查。
- 实际 ZIP 消费测试从归档读取版本，新增确切注册表版本消费入口，避免继续验证旧版本。
- 本轮测试结果和复现方式见 [0.3.2 证据](test-evidence/review-0.3.2.md)，发布及 CI 状态见 [release.md](release.md)。

## 保留边界

镜像物理偏移与单文件小于 2 GiB；字符串路径要求 UTF-8；特权还原不执行而明确报告；CLI 使用 JS/Node/Python，库验证 JS 与 Wasm-GC。六个压缩算法不是本项目原创。真实发行物验证目前为一个 OpenWrt 镜像，不等同广泛固件部署或穷尽模糊测试。

这些边界与申报目标保持一致，不能靠扩大文案隐藏。若主办方明确要求范围外能力，需要单独扩展并验证。
